# Time Lens — Gold Edition PWA

نسخة **PWA فعلية قابلة للتثبيت** لتطبيق Time Lens، بواجهة موبايل **أبيض + ذهبي مع لمسة كحلي في النصوص فقط**، مستوحاة من الشعار المرفق. لا تحتوي على Back-End أو قواعد بيانات.

## الشاشات

1. **الرئيسية:** شعار Time Lens الأصلي، واجهة فرعونية فاتحة وصورة حضارية وزر «ابدأ الرحلة».
2. **اختيار العصور:** ثلاثة كروت مصورة. **الدولة القديمة** و**الدولة الوسطى** مقفولتين (تظهر رسالة قريبًا عند الضغط)، و**الدولة الحديثة** هي المتاحة فقط.
3. **ملوك الدولة الحديثة:** كارت مصوّر **للملك رمسيس الثاني فقط**.
4. **تأكيد الاختيار:** «تم اختيار الملك بنجاح!» و«الملك المختار: رمسيس الثاني» مع اللوجو.

## التشغيل — Windows PowerShell

افتح فولدر المشروع في VS Code ثم افتح Terminal وشغّل:

```powershell
npx --yes serve . -l 4173
```

ثم افتح **http://localhost:4173** على الكمبيوتر.

> تنبيه: لو فتحت index.html بالضغط المزدوج (`file://`) ستظهر الواجهة، لكن تثبيت PWA و Service Worker لا يعملان بدون localhost أو HTTPS.

## النشر على Cloudflare Pages

1. افتح **Cloudflare → Workers & Pages → Create → Pages → Direct Upload**.
2. ارفع المجلد **Time-Lens-PWA-Gold** بمحتوياته (بدون Build Command).
3. افتح رابط Cloudflare Pages بالـ HTTPS.
4. على Android: استخدم زر التثبيت أعلى التطبيق أو قائمة Chrome → Install app.
5. على iPhone: افتح الرابط في **Safari → Share → Add to Home Screen**.

## محتويات المشروع

- `index.html`: صفحات التطبيق الأربعة.
- `styles.css`: التصميم المتجاوب، الأبيض والذهبي، وحركات التفاعل.
- `app.js`: التنقل والـ locks ورسالة النجاح وتعليمات التثبيت.
- `manifest.webmanifest`: إعدادات تطبيق PWA.
- `sw.js`: حفظ الصور والملفات محليًا لدعم العمل أوفلاين بعد أول تحميل.
- `assets/`: لوجو Time Lens المرفق، صور توضيحية مصممة مستخلصة من نموذج العرض الذي تم إنشاؤه للمشروع، وأيقونات التطبيق.

**مهم:** صور العصور والفرعون رسومات تصوّرية مصممة للواجهة وليست صورًا فوتوغرافية توثيقية أو نماذج ثلاثية الأبعاد. تجربة VR والذكاء الاصطناعي نفسها غير مفعّلة حسب المطلوب.

هذه النسخة مستقلة تمامًا، بدون Node build أو React أو استضافة باك إند.
